كان Windows يوقفك، ما تخافش: اكبس More info و من بعد Run anyway.

2 اربط Concat بـ Claude

حلّ الـ application متاع Claude (الـ onglet Code)، و حطّلو الـ prompt هذا مرّة برك:

Connect the Concat video editor to yourself as an MCP server. Concat is installed on this computer (Windows: %LOCALAPPDATA%\Programs\Concat\concat.exe, Mac: /Applications/Concat.app). Find the executable, check that `concat --mcp headless` answers, then add it as a user-level MCP server named "concat" with the arguments `--mcp auto`. Tell me when it is done and that I need to start a new session.

كي يقلّك ✓ مربوط، حلّ session جديدة.

3 ابعثلو الفيديو و التصويرة

ابعث لـ Claude الفيديو متاعك و تصويرة الـ background اللي تحبّ عليها، مع الـ prompt هذا:

With the Concat MCP tools, replace the background of my video:
1. Create a 9:16 (1080x1920, 30 fps) Concat project in a folder inside my user folder.
2. Import my video and my background picture.
3. Put the picture on lane 1, stretched to the video's length and covering the frame (raise it if the important part is hidden behind me); put my video on lane 2 above it.
4. Save, then turn on Concat's person cutout on my video clip: in concat.json add "cutout": {"mode": "auto", "subject": "person"} to that clip (Concat must be closed).
5. Export an mp4 next to the project and show me a frame.
6. Open the project in Concat for me (concat --project "<folder>") so I can adjust the colours.

الـ cutout يعملو Concat، و Claude يحضّرلك كل شي و يشغّلو

4 بدّل الألوان و export

في Concat: اختار الكليب › Inspector › Video › Adjust، و بدّل الألوان على كيفك.

Ctrl+S و من بعد Export 🎬
